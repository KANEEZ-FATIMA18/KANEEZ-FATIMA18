## 👩‍💻 About Me

I'm a **creative frontend developer** who genuinely cares about both the code and the design. For me, building a great web app means two things working together: clean, efficient logic under the hood — and a UI that feels intentional and polished on the surface.

I started with HTML & CSS and fell in love with the craft of turning a static design into something that actually *moves*, *responds*, and *feels* right in the browser. Now I work across the full MERN stack, but frontend is where my heart is.

When I'm not coding, I'm probably studying a Dribbble shot, tweaking animations until they feel *just right*, or breaking down how a website I admire achieves its effect.
